🎮 JogoTeca

JogoTeca é uma biblioteca de jogos online onde você pode cadastrar, editar e gerenciar seus jogos favoritos.

O projeto conta com front-end, back-end e banco de dados integrados, oferecendo uma experiência completa para o usuário.

🚀 Funcionalidades

📚 Catálogo de Jogos

Cada jogo possui as seguintes informações:

Nome

Categoria

Console


📝 Tabela de Jogos

Exibe todos os jogos cadastrados

Botão Editar → altera Nome, Categoria e Console

Botão Deletar → remove o jogo da biblioteca

🔐 Autenticação de Usuário

Criar novo usuário

Login e Logout

Sessão segura


➕ Cadastro de Jogos

Adicione novos jogos de sua escolha ao catálogo


🛠️ Tecnologias Utilizadas

Front-end: HTML/CSS/JS

Back-end: Flask

Banco de Dados: MySQL


📦 Como Rodar o Projeto

Clone o repositório:

git clone https://github.com/seuusuario/jogoteca.git

cd jogoteca


Configure o banco de dados no arquivo prepara_banco.py, alterando para as suas informações. caso tenha alguma duvida no arquivo tem um modelo de base

Inicie o servidor rodando o arquivo "Jogoteca.py"


Acesse no navegador:

http://localhost:5000
